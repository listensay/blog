First, open this website:

[https://www.jetbrains.com/](https://www.jetbrains.com/)

Download the IDE you want to crack. I chose PyCharm for this example. Click Download, then install it.



<img
  src="/affine-assets/b26b02a9856b9d30fc816961c8e365f144f7bcc113dbecc3a3238a6a59eb7494.png"
  alt=""
/>

After installation, open this website:

[https://ckey.run/](https://ckey.run/)

On the page, click "Installation Guide" where the arrow points.



<img
  src="/affine-assets/3d47f3c5be167c55cd3cbbce51cf92ddfac45b5b19431214b94be5566a33f98b.png"
  alt=""
/>

Copy the command for your operating system to activate the IDE automatically.



<img
  src="/affine-assets/bf0a078c254b65df971e54e0c3c01e839d5b7167e69c0218590502071ba72fbf.png"
  alt=""
/>

Run the command.



<img
  src="/affine-assets/2f9be3009653626ff060d524b42d1de28853205cd4de94bd20a8d04f09c521b5.png"
  alt=""
/>

Press Enter at each prompt to keep the default options.



<img
  src="/affine-assets/fa87410d04b7ff611a5672b694cc9b1e4bbcb427db4c03206f398a6df13bcd8a.png"
  alt=""
/>

When you see the result shown in the screenshot, the crack has succeeded. You can now open the software and try it.

If the software asks for an activation code, return to the website, select the matching IDE, copy its activation code, and paste it into the software.
